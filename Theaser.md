## will we ever get a V3 PCB ? (No)

Had fun making a lot of overdue changes in V2.7 and as a result I may create a V3 PCB with very small tweaks to the firmware

However my main reason was getting ride of the USB micro connector and migrate to a more modern version of the classic ESP32 vroom, on the other hand it doesn't make much sense

ESP32 vroom is going to be around for some time and conversion boards with more modern MCU to the current layout may become available in due time

Next main issue with the ESP32-C3 dev board is that it's lacking i/o pins so an extra 3-8 decoder will be needed

another reason is that one can buy on Ali-Express a ESP32 vroom with the USB-C connector and this solves all my current issue

So PCB V2.7 will be final one with it's gerbers and may get updated as needed, so far I have not seen any issue's with this PCB.
